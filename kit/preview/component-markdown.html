以下是统计近 30 天活跃用户的示例脚本：

python 
import pandas as pd

df = pd.read_csv("events.csv", parse_dates=["timestamp"])
active = (
    df[df["timestamp"] >= pd.Timestamp.now() - pd.Timedelta(days=30)]
    .groupby("user_id")
    .size()
    .reset_index(name="event_count")
)
print(f"活跃用户数：{len(active)}")
