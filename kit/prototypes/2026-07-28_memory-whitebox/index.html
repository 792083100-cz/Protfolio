记忆设置白盒化

调整「记忆」设置模块的功能，让用户可以感知并管理记忆内容
设置页 · 记忆 交互变更 页面级原型

背景

目前「记忆」设置对用户是黑盒 — 有哪些记忆、都记住了什么、什么时候会被使用，都无处感知。

痛点

  • 不知道 MyFlicker 记住了哪些信息
  • 想删除某条记忆时缺少入口
  • 「自动记忆」下的子能力划分不清晰
  • 提取频次、召回策略等参数无法调节

方案

  • 基于 ui_kits/setting/index.html 的设置页壳复用
  • 严格遵循已有设计规范（导航、卡片、行、Toggle）
  • 顶部：配置卡片 — 被动记忆 / 自动提取（含频次子项）/ 自动召回 / 近期活动摘要
  • 底部：记忆列表卡片 — Tab 分类 + 「创建」按钮 + 可编辑/删除的记忆条目
