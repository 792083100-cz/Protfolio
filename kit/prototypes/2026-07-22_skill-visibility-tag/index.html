原型 Skill 可见范围标签
2026-07-22 · 添加技能弹窗
需求背景
技能存在公开、仅管理员、部分可见三种权限，用户打开「添加技能」弹窗时无法感知当前技能的可见范围，容易误操作或错误理解权限。
痛点
列表行缺乏权限信息，管理员发布的受限技能与公开技能外观完全一致，普通用户无法区分；管理员也无法快速确认权限设置是否正确。
解决方案
在 Skill 标题右侧前置可见范围 Tag，公开 / 仅管理员可见 / 部分可见三态。后两态内嵌 ⓘ 图标，hover 展示 Popover 成员列表，超出 240px 自动截断滚动。
本次改动
新增可见范围 Tag，复用 .mf-tag--info，排在场景分类 Tag 之前
「仅管理员可见」「部分可见」Tag 内嵌 ⓘ 图标（--status-primary-default），hover 展示 .mf-popover 成员面板
Popover 成员列表支持部门、用户组、个人三类混排，部门和用户组默认置顶
.mf-popover__list 新增 max-height: 240px; overflow-y: auto，超出截断滚动
