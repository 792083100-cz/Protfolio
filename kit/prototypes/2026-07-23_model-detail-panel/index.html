模型选择器 · 二级详情面板

在模型选择下拉中，鼠标 hover 到模型行时，在行的左侧弹出模型详情卡片。
包含：模型名称、服务状态（绿/橙/红）、可用能力列表、仅用私有部署开关（按需展示）。

    结构解析
    每个 .mf-model-picker__item 设 position:relative，内嵌 .mf-model-detail；CSS hover 驱动，无 JS。
    .mf-model-picker__item position: relative
    ├─ 正常列表内容（icon / name / meta / tag）
    └─ .mf-model-detail opacity:0 → 1 on :hover，left:-228px
    ├─ __head 名称 + signal 图标 + 状态文字
    ├─ __section "可用能力" 标签
    ├─ __caps 能力列表（i-success + 文字）
    └─ __toggle-row 仅私有部署（按需，mf-switch）
