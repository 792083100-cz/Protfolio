原型 会话归档
2026-07-27 · 会话管理
需求背景
用户希望将某些历史会话从主列表隐藏，但不希望就此删除，以便未来查阅或恢复。当历史会话累积较多时，主列表信息负载过重，需要一种轻量、可逆的会话整理方式。
痛点
历史会话只能删除，无法「暂时隐藏」。删除后无法找回，导致用户对重要会话犯怒而不格。同时缺少操作反馈（Toast）和二次确认（Dialog）机制，误操作风险高。
解决方案
主列表会话行「……」菜单增加「归档」入口，归档后 Toast 全局提示 + 带「去查看」跳转。已归档列表支持单条/清空二次确认，恢复后自动选中该会话。
本次改动
  • 会话列表行 hover 展示「……」更多操作按鈕，点击唤起 .mf-menu 菜单（分享 / 重命名 / 移动至 / 置顶 / 归档 / 删除）
  • 点击「归档」后会话从侧边栏移除，插入设置页已归档列表顶部
  • 弹出 .mf-notif--float.mf-notif--success Toast，文案带「去查看」跳转设置-已归档页
  • 已归档页支持单条「徒标」确认 Dialog、「恢复」展示恢复 Toast + 「去查看」选中会话
  • 「清空全部」二次确认 Dialog 展示当前归档数量，确认后批量清除
  • 删除 / 恢复按鈕 hover 展示 .mf-tooltip 功能提示
