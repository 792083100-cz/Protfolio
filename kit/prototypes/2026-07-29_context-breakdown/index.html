原型 上下文成分占用拆分展示
2026-07-29 · Context Breakdown · v1.0.0
需求背景
为提升上下文使用的可解释性，将上下文占用量拆分展示不同上下文成分的占用情况，帮助用户理解当前会话的上下文结构，建立对长会话行为的预期。
痛点
当前仅展示总使用率（如 44%），用户无法判断消耗来源，缺乏对 System Prompt / Tools / Skills / MCP 等静态配置的感知，不知道哪一项应当管理。
解决方案
在 chatting 页 notice 行展示上下文使用摘要 + 「查看详情」/「直接上下文」入口；点击「查看详情」弹出成分面板（彩色进度条 + 7 成分列表）。输入框换用 Code 模式。
本次改动
  • chatting 页输入框替换为 Code 模式（component-chat-input-code.html）：Claude Code · Claude Sonnet 4.6 · 执行前询问 + 项目区
  • notice 行新增：上下文使用：44%（89K / 200K） + 「查看详情」（打开面板）+ 「直接上下文」（清空当前会话上下文）
  • 面板 .proto-ctx-panel：header + 已使用百分比 + 彩色分段进度条 + 7 项成分（System prompt / Tool definitions / Rules / Skills / MCP / Subagent definition / Conversation）
  • 面板支持 × 关闭 / 点击外部关闭；所有新增样式在 .proto-ctx-* 命名空间内，不污染 components.css
